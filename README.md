# dsh-session-delete-cn

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 侧栏补上一个**彻底删除会话**的菜单项：不是归档，是把会话真的从磁盘上删掉。

> **这不是 npm 上的 `dsh-session-purge`。**
> 那个项目（作者 verdana，仓库 `github.com/verdana/dsh-session-purge`）是另一份独立实现，走的是
> "回收站"路线——删除先移入回收站、可复原，到期再清理。本项目是**另写的**、功能刻意不同的实现：
> 只有一个动作，**当场永久删除，没有回收站、不可复原**。两者包名、代码、数据目录都不相同，可以并存，
> 但不要同时装，否则会话菜单里会出现两个删除入口。

## 它做什么

会话行的右键菜单 / 行尾 `…` 菜单里多一项 **彻底删除会话…**（红色危险项，排在「归档」之后）：

1. 弹出确认框，写明目标会话标题和"不可恢复"；
2. 确认后删除该会话的本地日志目录
   `<DSH_HOME>/sessions/<项目目录>/<会话目录>/`（含全部 `session.v*.jsonl*` 文件）；
3. 同时把会话从工作区账目里摘除，侧栏那一行随即消失。

## 和「归档」的区别

| | 归档 | 彻底删除 |
|---|---|---|
| 侧栏是否显示 | 隐藏 | 消失 |
| 日志文件 | 保留在磁盘上 | 删除 |
| 能否找回 | 能（取消归档） | 不能 |

## 安装

前置：DSH `0.2.2`（Web / 桌面版均可）。

**方式一（推荐）**：DSH 桌面版 → **插件 / Plugins** → **添加插件** → 选择本目录。安装后刷新页面；若菜单没出现，重启一次 DSH。

**方式二**：用 `plugin_manager` 的 `install_bundle`，`target` 传本目录的绝对路径（效果同上：把目录 link 进 profile）。

> 安装是把本目录 **link** 进 profile 的，不是复制。所以装好后别移动或删除这个目录，否则插件会失效；想换位置就重新安装一次。

## 用法

在左侧栏任意会话行上点 `…`（或右键），菜单底部就是 **彻底删除会话…**。

文案固定中文，不跟随界面语言。早先版本按 `ctx.locale.getLocale()` 的返回值切换中英文，但那个快照的字段是 `active` 而不是 `id`，读错字段会永远回落到英文——所以这层探测被整个去掉了，避免同类问题。

## 安全设计

- **运行中或已被打开的会话一律拒绝删除**（Host 侧检查 `ctx.sessions`），避免删掉正在写入的日志；
- 只删持久化层自己给出的那个**会话目录**，并对目录名做形态校验（项目目录、会话根目录、`_no-cwd` 等一律拒绝），不会误删上级目录；
- 删除顺序是「先归档 → 再删文件 → 最后摘账目」：删文件失败会立刻撤回归档，所以不会出现"侧栏里看不见、但文件还在"的半删状态；
- 失败原因（会话在运行 / 找不到记录 / 无权限 / 路径校验失败）会通过宿主通知条原样报给你。

## 已知限制

- 拒绝删除"当前正在使用"的会话：先关闭它（或重启 DSH）再删；
- **没有回收站**：确认即永久删除，删掉的会话找不回来；
- 只清理会话日志目录与工作区账目；会话检索索引（如 SQLite FTS）中可能残留旧条目，不影响使用；
- 依赖 `sessionPersistence` 与 `workspaceRegistry` 两个宿主服务；缺失时菜单会提示"宿主缺少会话存储服务"。

## 兼容性

- DSH `0.2.2`：依赖官方可扩展上下文菜单 `ctx.contextMenus`（`target: 'session'`）。0.1.x 没有这个扩展点，需要 DOM 注入才能实现，本插件不那样做；
- 平台：Windows / Linux / macOS 通用（只用到 `node:fs`、`node:path`）。

## 实现

| 文件 | 作用 |
|---|---|
| [`index.js`](index.js) | Host 半：`POST /dsh-session-delete-cn/delete` 同源路由 → 定位 → 归档 → 删目录 → 摘账目 |
| [`client.js`](client.js) | Client 半：注册到 `ctx.contextMenus`，不做 DOM 注入，宿主升级不易失效 |
| [`cordis.patch.yml`](cordis.patch.yml) | 随包生效的挂载行（id 必须与包名一致） |
| [`locale/`](locale) | Plugins 页里的标题与说明 |
| [`icon.svg`](icon.svg) | Plugins 页图标 |
